# 勤務区分の設定が、どこへ効くか

勤務区分は設定の画面から入れられる項目を多く持ちます。入れられるのに
どこにも効かない項目があると、入れた人はそれが効いていると考えます。
効いていないことは、結果を見ても分かりません。

この文書は、項目ごとに次のどれかを決めます。

- **予定へ写す** — 勤務予定を作るときに値を移す。以後は勤務予定が正本。
- **計算で使う** — 日次の計算が勤務区分から直に読む。
- **表示だけ** — 画面の見え方だけに使い、計算にも集計にも入れない。
- **対応しない** — 意図して使わない。理由を書く。

## 一覧

| 項目 | 扱い | 中身 |
| --- | --- | --- |
| `code` | 対応しない | 版をまとめる識別子。同じ `code` の行が期間で並ぶ |
| `internalName` | 表示だけ | 管理の画面で探すための名前 |
| `displayName` | 表示だけ | 従業員に見せる名前 |
| `categoryType` | 予定へ写す | 勤務予定の日種別になる。法定休日・休暇・欠勤はここで決まる |
| `effectiveFrom` / `effectiveTo` | 計算で使う | 対象日に効いている版を選ぶ |
| `scheduledStartMinutes` / `scheduledEndMinutes` | 予定へ写す | 勤務予定の所定時刻のひな形 |
| `prescribedMinutes` | 計算で使う | 所定労働分数。決めてあれば、始業から終業までの長さより優先する |
| `deemedMinutes` | 計算で使う | みなし労働分数。裁量労働の割当があればそちらが優先する |
| `nightStartMinutes` / `nightEndMinutes` | 計算で使う | 深夜帯の上書き。空なら計算規則の版に従う |
| `gapTreatment` | 計算で使う | 区間と区間の間を休憩として数えるか |
| `fixedBreaks` | 計算で使う | 打刻が無くても引く休憩の時間帯 |
| `autoBreaks` | 計算で使う | 実労働が閾値を超えたときに引く分数 |
| `countsAsWorkingDay` | 計算で使う | その日を出勤日として数えるか。日次の結果に残し、月次と給与が読む |
| `shift` | 表示だけ | シフト表での見え方 |
| `color` | 表示だけ | 画面上の色 |

## 決めた理由

### `categoryType` を予定へ写す

勤務予定は日種別を持ち、計算はそれを見て法定休日・法定外休日・休暇・欠勤を
分けます。勤務区分の種別を写さないと、法定休日として作った勤務区分を
割り当てても、予定はふつうの勤務日のままになります。

写すのは、日種別を明示していないときだけです。明示した値のほうが後から
決めた意思なので、そちらを優先します。

周期から生成する経路では、勤務区分の種別を優先します。周期が持つのは
勤務日か休日かの別だけで、法定休日や休暇は表せません。

### `prescribedMinutes` を計算で使う

所定労働時間は取り決めで決まる値であり、始業から終業までの長さから休憩を
引いたものとは限りません。決めてあればそちらを採り、決めていなければ
これまでどおり勤務予定の時刻から導きます。

### `countsAsWorkingDay` を計算で使う

出勤日数は「実労働が 0 分より多い日」を数えていました。勤務区分の設定は
結果に現れず、設定できるのに効かない値でした。

数える側で勤務区分を辿り直すことはしません。月次と給与は保存済みの日次から
組み立てるため、あとから区分を直すと締めた月の日数だけが動きます。
その日の計算と一緒に固めれば、締めた値は締めた時点のまま残ります。

### 表示だけの項目

`internalName`・`displayName`・`shift`・`color` は、計算にも集計にも
入れません。計算の入力の指紋にも入れません。入れると、結果が変わらない
編集で計算の版が増え、履歴から本当の変更を追えなくなります。
