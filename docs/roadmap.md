## 各フェーズの範囲

### P0 基盤初期化

README、ライセンス、開発方針、日英用語集、モジュール境界、ロードマップ。

### P1 セルフホスト基盤

pnpm workspace、TypeScript 設定、Hono サーバー、React/Vite クライアント、
PostgreSQL、SQL マイグレーション、Docker Compose、health / readiness、ローカル起動手順。

### P2 組織と認証

Workspace、組織、拠点、部門、利用者、従業員、ロール、ローカル認証、セッション、
テナント境界の強制、日本語・英語切り替え。

### P3 最小打刻

一人・一日を対象とした出勤・退勤、当日表示、不変の打刻イベント、
冪等な二重送信防止、監査記録。

### P4 休憩と修正

休憩開始・終了、複数休憩、日跨ぎ勤務、打刻修正、修正理由、変更前後の記録、履歴表示。

### P5 勤務予定と計算

勤務カレンダー、勤務パターン、所定労働時間、実労働、休憩、所定内外、休日、深夜帯を扱う
決定的な計算エンジン。入力版・ルール版・計算根拠の保存。

### P6 申請・承認・締め

日次申請、承認、差し戻し、取消、コメント、月次締め、締め解除、確定後の編集制御。
状態遷移は fsmxjs を使う。

### P7 スマートフォン打刻

モバイル優先の打刻 UI、明確な状態表示、ワンタップ操作、オフライン待機、再送、
冪等受理、アクセシビリティ。

### P8 打刻端末プロトコル

端末登録、端末資格情報、署名イベント、連番、再送、失効、Agent シミュレーター、
JSON Schema、OpenAPI。OS 固有実装は行わない。

### P9 IC カード試作

ローカル Agent 用のカード資格情報アダプター。生のカード識別子を直接保存せず、
登録・失効・重複防止・出退勤を扱う。実機非依存のテスト用アダプターを用意する。

### P10 PC セッション試作

ログイン・ログオフ・ロック・解除の観測イベントを扱う Agent 境界とシミュレーター。
勤怠との乖離を本人・管理者へ提示する。自動確定はしない。

### P11 柔軟な勤務制度

休暇、欠勤、休日、変則的な勤務周期、週休 3 日、複数勤務パターン、有効期間付き設定。
曜日固定や週 5 日勤務をコアへ埋め込まない。

### P12 複数組織と契約

雇用元、勤務先、受入組織、契約期間、配属、勤務先別の閲覧権限、外部承認者、
日次・月次承認。

### P13 監査と異常検出

打刻と PC 記録の乖離、確定後変更、大量修正、端末時計差、連番欠落、重複イベントの検出。
根拠付きで表示・出力できるようにする。

### P14 外部連携の初期実装

CSV 入出力、汎用給与出力、Webhook、API キーとスコープ、connector SDK、
バックアップ・復元、サンプルデータ、デモモード、セルフホスト導入手順。

ここで実装したのは各機能の最初の形までです。公開に必要な水準に達しているかは
P15 で判定します。P12 も同様に、契約・配属・閲覧範囲の登録までを範囲としており、
関連機能を網羅した状態ではありません。

### P15 公開前セキュリティ・整合性是正

`release-blocker` を付けた Issue の解消。認可マトリクスの作成と維持。
競合制御・再送・秘密情報の扱いの是正。公開判定チェックリストの作成。
Git 履歴を含む秘密情報の検査。ライセンス方針の再確認。

ライセンスは現在 MIT です。当初 AGPL-3.0 を想定していた経緯があるため、
次を確認したうえで方針を決めます。Agent による自動変更は行いません。

- Git 履歴上の著作者とコントリビューター
- 外部コードの取り込みの有無
- 依存ライセンス
- セルフホスト版の再配布方針
- 改変した SaaS にソース公開を求めるか
- SDK を別ライセンスにするか

### P16 認証・運用強化

パスワード変更、セッション一覧と一括失効、ログイン試行制限、Origin / CSRF 対策、
マイグレーションの排他、安全なバックアップ・復元、本番向けコンテナ、
依存脆弱性検査、SBOM。

### P17 管理画面と多言語品質

端末、IC カード、API キー、Webhook、勤務周期、休暇種別、契約、配属、閲覧範囲の管理画面。
日本語・英語のエラー表示。英語版の導入文書。

### P18 勤務制度拡張

時間単位休暇、半日休暇、会社別ルール、ルールの有効期間、異常検出のしきい値、
日本向けルールパック、計算根拠の説明の拡充。

### P19 契約・外部承認ワークフロー

契約の申請、承認、差し戻し、取消、終了。複数段階承認。
勤務先側の日次承認と月次承認。作業報告。

### P20 外部連携の耐久性

transactional outbox、Webhook の再送、指数バックオフ、デッドレター、手動再送、
CSV マッピング、インポートの事前検証、connector SDK の版管理。

### P21 ローカル Agent 実装

Windows サービス、PC セッションの取得、カードリーダーのアダプター、
暗号化したローカルキュー、インストーラー、更新と失効。

### P22 デモ・マネージド運用準備

公開デモ、定期リセット、Row-Level Security、オブジェクトストレージ、
構造化ログ、メトリクス、水平スケール試験。

マネージド提供は、利用の要望が出た場合にのみ判断します。P22 の完了は
マネージド提供の開始を意味しません。
