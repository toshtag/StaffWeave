# CSV 出力の無害化

StaffWeave の CSV 出力には、利用者が決めた文字列（従業員の表示名、従業員番号、端末名）が入ります。
これらが表計算ソフトで数式として動かないようにするための決めごとです。

## 何が問題か

Excel と LibreOffice は、引用符を外したあとのセルの内容を数式として評価します。
値を `"` で囲んでも解釈は変わりません。

```csv
"employee_number","display_name"
"E001","=HYPERLINK(""http://example.com"",""社内資料"")"
```

この出力を開くと、`display_name` の欄は文字列ではなくリンクになります。
出力は給与連携のために外部の担当者へ渡す前提であり、
受け取る側が StaffWeave の利用者とは限りません。

## どうするか

書き出す値が次の文字で始まる場合、先頭へ `'`（アポストロフィ）を付けます。

| 文字 | 意味 |
| --- | --- |
| `=` | 数式 |
| `+` | 数式（一部の実装） |
| `-` | 数式・負号 |
| `@` | 関数呼び出し |
| タブ・復帰 | 前置きを飛ばして数式として読ませる形 |

表計算はこの `'` を「以降を文字列として扱う」指示として読み、セルには表示しません。
判断は `packages/domain/src/integration/csv.ts` の `toCsvValue` だけで行い、
出力ごとには書きません。勤怠 CSV・給与 CSV・異常 CSV はいずれもここを通ります。

数値として渡した値には印を付けません。分数などの列は数値のまま出します。
負の数を文字列として渡した場合は印が付きます。

## 取り込み側から見える差

`parseCsv` は、`'` の次が上の表の文字である場合にだけ `'` を外します。
StaffWeave が書き出した CSV を StaffWeave が読み戻すと、値は元のままです。

他のソフトで開いた場合は、次のように見えます。

| 見る場所 | 見える値 |
| --- | --- |
| 表計算（Excel / LibreOffice） | `=HYPERLINK(...)`（数式としては動かない） |
| テキストエディタ | `"'=HYPERLINK(...)"` |
| StaffWeave の取り込み | `=HYPERLINK(...)` |

取り込み側が `'` を外さない実装の場合、値の先頭に `'` が残ります。
数式として動かせる値を、そのままの形で渡す方法は用意していません。

`'` で始まるだけの値（例: `'ないしょ`）は、次の文字が数式の始まりではないため
印とは扱われず、そのまま書き出して読み戻せます。
