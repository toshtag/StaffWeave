# 正式リリース・実運用投入判定の記録

判定を行うたびに、日付を名前にした文書を 1 つ追加します。
過去の記録は書き換えません。判定は「いつの、どのコミットに対して行ったか」で意味が決まります。

この記録は、次を示すものではありません。

- GitHub リポジトリの公開・非公開
- 法令への適合
- 無停止運用や、障害時にデータが失われないこと
- マネージド提供の可否

条件そのものは [../roadmap.md](../roadmap.md) の「正式リリース・実運用投入判定」を正本とします。

## Issue の状態について

Issue と PR の現在の状態は GitHub を正本とします。
この記録に書くのは、判定した時点で数えた件数です。
`pnpm verify` から GitHub へ問い合わせて件数を確かめることはしません。
オフラインで検証できなくなり、GitHub の障害でコードの検証まで失敗するためです。

現在の状態は、判定のたびに次で確かめます。

```sh
gh issue list --state open --label release-blocker
gh issue list --state open
gh pr list --state open
```
