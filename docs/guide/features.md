# できること

いま実際に動くものだけを並べます。

動くことと、安心して本番で使えることは別です。労働法令に合っているか、
止まらずに動くか、脆弱性が無いかは保証しません。

リリース候補の条件は満たしていますが、実機・第三者・試行運用の確認が済んでいません。
正式なリリースタグはありません（[checklist.md](../release/checklist.md)）。

## 組織と利用者

- ワークスペース、組織、拠点、部門、従業員の登録と一覧
- メールアドレスとパスワードでのログイン、セッション、パスワードの変更
- 本人によるログイン中の端末の一覧と、個別・一括のログアウト
- ロールによる権限制御（ワークスペース管理者 / 組織管理者 / 従業員）
- 雇用元と受入組織の契約、配属、勤務先別の閲覧権限と外部承認者
- 日本語と英語の切り替え

## 打刻と勤務時間

- 本人による出勤・退勤・休憩の打刻と、当日の状態表示
- 打刻の修正・取消・追加。理由が要ります。元の記録は残り、変更前後を追えます。
  400 日前まで遡れます。締めた期間は直せません
- 日付をまたぐ勤務、1 日に複数の勤務区間（中抜け・分割シフト・呼び出し）、
  夏時間の切り替わる日。時刻は拠点の時間帯で表示・入力します
- 実労働・休憩・所定内外・深夜帯・法定内外・法定休日と法定外休日・遅刻早退の計算。
  適用開始日つきの計算規則で、過去の集計は当時の版のまま残ります
- 版管理された勤務区分（所定時刻、固定休憩、自動休憩、みなし時間、深夜帯の上書き、
  中抜けの扱い、シフト属性）
- 勤務パターンと勤務予定、勤務周期からの予定の生成（曜日を前提にしません）
- 労働形態の割当（通常・フレックス・裁量・変形）

労務計算の値は、法令上の普遍的な既定値として持ちません。事業者が設定します。
未設定の区分は 0 ではなく「未設定」として示します。

## 休暇

- 付与・取得・失効・手当て・取消を追記で積む台帳。残数は保存せず、
  任意の時点の値を台帳から組み立てます。期限の近い付与から先に消化します
- 勤続の段ごとの付与規則と、それに従った自動付与・一斉付与・CSV 取込。
  段を置かないかぎり 1 分も付与しません。同じ日への二重付与は止まります
- 自動付与は日次の command（`pnpm leave:grants`）が動かします。
  1 日に何度呼んでも結果は変わりません
- 休暇管理簿（期首・付与・消化・失効・期末）と、失効の予定

## 申請と確定

- 組織が定義する申請種別と、1〜4 段の承認、差し戻し、出し直し、取消、代理。
  段数は提出時の定義を写して固定します
- 申請・承認・差し戻し・取消・代理承認を、製品内の通知として本人と承認者へ届ける
- 承認しきった申請を反映する。休暇はその場で台帳へ、残業・休日出勤・打刻修正は
  日次の計算へ。残業は申請した上限時刻までを認定し、超えた分を分けて出します
- 月次の集計と、締める前の確認（退勤していない日・承認待ち・差し戻し）
- 週・フレックスの清算期間・変形労働の対象期間の集計と、総枠との差
- 月次締めと締め解除。締めた時点の値を固めるため、あとから訂正しても
  給与へ渡した値は動きません
- 長時間労働の警告と、休暇の失効予定。上限も期限も事業者が決めます
- 確定後の変更・大量修正・端末時計差・連番欠落・重複打刻の検出

## 端末と観測

- スマートフォン向けの打刻画面（オフライン待機・自動再送）
- 打刻した場所の記録。組織ごとに取ると決めたときだけで、既定は取りません
- 打刻端末の登録・失効と、署名付きイベントの受理
- 端末で常駐する Agent。送れなかった打刻をディスクへ残し、順に送ります。
  配布物は、リポジトリを持たない端末でそのまま動く形で作れます
- IC カードの指紋の登録・失効と、カードイベントの受理。生の識別子は送らず保存もしません
- 端末シミュレーター（実機なしで取り決めを確認できる）
- PC セッションの観測記録の受理と、打刻との食い違いの提示。自動確定はしません

詳細は [device-agent.md](device-agent.md)。

## 外部連携と運用

- CSV の入出力、給与連携向けの汎用出力、API キーとスコープ
- Webhook の送信・署名・再送・諦めた通知の置き場と、人による送り直し
- 外部連携を作るための connector SDK
- バックアップと復元。書き出して戻したものが元と同じであることを毎回確かめます
- デモ用データ

詳細は [integrations.md](integrations.md) と [backup.md](../operations/backup.md)。

## 設定の画面

上でモジュールを切り替え、左でその中の設定を選びます。組織・拠点・部門・従業員・
閲覧範囲・勤務区分・計算規則・労働形態・休暇種別・休暇台帳・申請種別・月次を扱えます。

見られない設定は入口ごと出しません。従業員・勤務区分・申請種別・休暇の付与は
CSV でまとめて入れられます。1 行でも読めなければ 1 行も取り込まず、
読めなかった行を位置つきで返します。

## まだ無いもの

- 端末・IC カード・Webhook・契約・配属の設定画面。API では扱えます
- 招待・パスワード再設定・メールアドレスの変更。管理者が作り、初回のパスワードを渡します
- MFA と SSO
- 実機の IC カード読み取り装置と、Windows 実機での端末再起動の確認。
  作る側は揃っていますが、実機では確かめていません
- 端末の自動更新。配布物を置き直して入れ替えます
- 公開デモ、Row-Level Security、メトリクスとアラート、保持期間を過ぎたデータの自動削除
