# できること

いま実際に動くものだけを並べます。

動くことと、安心して本番で使えることは別です。労働法令に合っているか、
止まらずに動くか、脆弱性が無いかは保証しません。正式なリリースタグもまだありません。

一部だけ動くものや、作らないと決めたものまで含めた一覧は
[capability-matrix.md](../product/capability-matrix.md) にあります。

## 動くもの

### 組織と利用者

- ワークスペース、組織、拠点、部門、従業員の登録と一覧
- メールアドレスとパスワードによるログイン、セッション、ログアウト、パスワードの変更
- 本人によるログイン中の端末の一覧と、個別・一括のログアウト
- ロールによる権限制御（ワークスペース管理者 / 組織管理者 / 従業員）
- 日本語と英語の切り替え
- 雇用元と受入組織の契約、配属、勤務先別の閲覧権限と外部承認者

### 打刻と勤務時間

- 本人による出勤・退勤・休憩の打刻と当日の状態表示（追記のみ・二重送信防止・監査記録つき）
- 日付をまたぐ勤務の一日としての扱い。ただし夏時間の切り替わる日は、
  業務日を前日と判定することがあります
- 打刻の修正・取消・追加（理由必須、元の記録は残り、変更前後を追える）
- 勤務パターンと勤務予定の登録
- 勤務周期による勤務予定の生成（週休 3 日・2 勤 2 休など、曜日を前提にしない）
- 実労働・休憩・所定内外・深夜帯・休日労働の決定的な計算（入力版・ルール版・根拠つき）。
  法定内と法定外、法定休日と法定外休日、遅刻・早退はまだ分けていません
- 休暇・欠勤を「その日の状態」として記録し、分数として集計する。
  残数、有効期限、付与、休暇の申請はまだありません
- 有効期間付きの制度切り替え

### 申請と確定

- 日次の申請・承認・差し戻し・取消と、その履歴
- 月次締めと締め解除、確定後の編集制御
- 確定後の変更・大量修正・端末時計差・連番欠落・重複打刻の検出と、根拠つきの表示・CSV 出力

### 端末と観測

- スマートフォン向けの打刻画面（オフライン待機・自動再送・冪等受理）
- 打刻端末の登録・失効と、署名付きイベントの受理（連番・時計差・受信記録つき）
- 端末シミュレーター（実機なしで取り決めを確認できる）。
  いま署名付きイベントを送っているのはこれで、実機の端末ではありません
- IC カードの指紋の登録・失効と、カードイベントの受理（生の識別子は送らず保存もしない）。
  識別子はシミュレーターへ手で入力します。実機のリーダーからは読み取れません
- PC セッションの観測記録の受理と、打刻との食い違いの提示（自動確定はしない）。
  OS から自動で送る常駐サービスはまだありません

詳細は [device-agent.md](device-agent.md)。

### 外部連携と運用

- CSV の入出力、給与連携向けの汎用出力、Webhook、API キーとスコープ
- 外部連携を作るための connector SDK
- API キーの作成・一覧・失効の管理画面（日本語・英語）
- バックアップと復元、デモ用データ

詳細は [integrations.md](integrations.md) と [operations/backup.md](../operations/backup.md)。

## まだ無いもの

- 勤務区分。始業・終業・休憩の合計分数までは持てますが、固定休憩、自動休憩、
  みなし時間、シフトの色、集計への算入可否は持てません。
- 法定内と法定外、法定休日と法定外休日、遅刻・早退・始業前・終業後の計算。
- 1 日に複数の勤務区間。退勤したあとの再出勤は受け付けません。
- フレックスタイム制、裁量労働制、変形労働時間制。
- 休暇の残数。付与、有効期限、失効、時間単位・半日単位の取得、休暇の申請。
- 申請区分と段階承認。いまあるのは日次勤怠の 1 種類・1 段階だけです。
- 申請・承認・差し戻しの利用者への通知。Webhook は外部システム向けで、代わりにはなりません。
- 管理画面。端末・IC カード・Webhook・勤務周期・休暇種別・契約・配属・閲覧範囲は
  API では扱えますが、画面はまだ API キーの分だけです。
- 画面の時刻を拠点の時間帯で表示・入力すること。いまは閲覧者のブラウザの時間帯を使います。
- 24 時間より前の時刻への訂正。オフライン打刻と同じ検証を使っているため断られます。
- 管理者による他の利用者のセッションの失効。権限・監査・退職処理と合わせて別途扱います。
- Webhook の自動再送とデッドレター。送信の失敗は記録しますが、到達は保証しません。
- 実機で動くローカル Agent（Windows サービス、カードリーダー、インストーラー、自動更新）。
  いまあるのは取り決めとシミュレーターです。
  据え置き端末・IC カード・PC セッションは、受け取る側だけが動きます。
- 打刻時の位置情報。
- 公開デモ、Row-Level Security、構造化ログ、メトリクス。

どの順で作るかは [roadmap.md](../roadmap.md)、個々の課題の進み具合は GitHub の Issue を見てください。
